Welcome to my site!

I'm CoderGreensparrow, a random programmer-to-be on the Interwebz. I thought I'd recode my old GitHub Pages, so here it is. This page will function as a hub to my other projects on GitHub. Here are some:

  • Rovógép (Old Hungarian rune "carver" machine): Transcribes modern Hungarian writing (Latin alphabet) to Old Hungarian runes (Székely-magyar rovásírás).
  • PEKSS (Parametrically Engineered Kinetic Speech and Singing): A custom parametric "Klatt-like" (random guide for that) formant speech synthesizer with simplified coarticulation dynamics. It was made with a lot of help from LLMs, but the synthesizer itself doesn't use AI. (I'm not a linguistics professor, nor am I a professional software engineer, so I had to use AI models for this ambitious project if I wanted to complete it in a shorter amount of time. That being said, I had sometimes felt like my brain was melting as I was planning out the functionality of the software, the synthesis pipeline etc.) Work in progress project. Commercial Japanese vocal synthesis software served as inspiration, like Vocaloid, especially their voice and character Hatsune Miku, and others, such as SynthV. (I am not affiliated with them in any way, this is basically fan enthusiasm.)
  • oscdraw: Python package for drawing things on an oscilloscope in real time. The works of the duo behind “Jerobeam Fenderson” served as the primary source of inspiration, definately check out their oscilloscope music, as well as their site! (I should disclose that I am not affiliated with them in any way whatsoever, they were my primary inspiration when I was doing my oscilloscope stuff.)
  • OLNMLN interpreter (GH Pages offline): An old, not very good esolang (esoteric programming language, programming languages with goals other than standard use, like artistic reasons or jokes). It can run a Deadfish interpreter though (which is another esolang). The description of the language is available on the Esolang Wiki.
  • japanese-video-subtitles: One-off project, in which I used OpenAI's Whisper model to transcribe Japanese videos and generate subtitles for them automatically. The subtitles are multifaceted, which means there are multiple of them at the same time. There can be the original Japanese transcription, turned into subtitles, with optional furigana above them, or even rōmaji. And of course, machine translation can be turned on too. Basically, this is a tool for fully automated subtitles, potentially for Japanese study.
